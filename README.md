# panda-explorer

Тренажёры китайского для учеников. `index.html` — выбор ученика, `app.html?student=<id>` — тренажёр,
словари лежат в `data/<id>.json`.

## Формат `data/<id>.json`

```jsonc
{
  "name": "Аскар",
  "book": "Easy Steps to Chinese 1",
  "showPinyin": true,            // необязательно: показывать пиньинь под иероглифами (если ученик их пока не читает)
  "modes": ["listen", "trap"],   // необязательно: порядок режимов для этого ученика
  "focus": {                     // необязательно: блок «Задания от учителя» на главной
    "date": "04.10", "title": "Домашка к 11.10", "note": "…",
    "tasks": [{ "topic": "t7", "mode": "sounds", "label": "Звуки: j · q · x" }]
  },
  "topics": [
    { "id": "t7", "lesson": 7, "em": "👨‍👩‍👧", "t": "Члены семьи", "cn": "家庭成员",
      "tag": "Урок 7",           // необязательно: подпись на карточке (по умолчанию «Урок N» / «Сверх учебника»)
      "w": [["哥哥", "gēge", "старший брат"]] }
  ],
  "traps": [                     // необязательно: «Ловушки» — слова, которые ученик путает
    { "t": "姐姐 или 弟弟?", "note": "j читается «цз», а не «д»",
      "w": [["姐姐", "jiějie", "старшая сестра"], ["弟弟", "dìdi", "младший брат"]] }
  ],
  "sentences": [
    { "lesson": 7, "tk": ["我", "家", "有", "五", "口", "人"], "ru": "В моей семье пять человек." },
    { "lesson": 0, "topic": "football", "tk": ["我", "有", "球"], "ru": "У меня есть мяч." }
  ]
}
```

Фразы попадают в тему по полю `topic`, а без него — по номеру урока (`lesson: 0` — во все темы «сверх учебника»,
у которых нет своих фраз).

## Режимы

Карточки · Выбери перевод · На слух · Верно или нет · Ловушки · Тоны · Звуки (j/zh/z, q/ch/c, x/sh/s…) ·
Скажи сам (микрофон, распознавание речи браузера; без него — самопроверка) · Впиши пиньинь · Собери фразу ·
Вставь слово · Фраза на слух · Молния · Пары.
